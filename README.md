# FitTracker

FitTracker is an Android fitness application designed to help users track physical activity, nutrition, and health progress.

## Overview

The application provides users with tools to monitor their fitness-related information and track their progress toward personal goals.

The project was developed as a native Android application using Java.

## Features

* Track physical activities and workouts
* Track nutrition and food-related information
* Monitor fitness progress
* Set and track fitness goals
* Store and manage fitness-related data

## Technologies

* Java
* Android SDK
* Gradle
* Android Studio
